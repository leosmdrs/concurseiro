## Como a CEBRASPE cobra

- Elementos do trabalho de asseguração: relação de três partes (auditor, parte responsável, usuários previstos), objeto, critérios apropriados, evidências suficientes e apropriadas, relatório.
- Asseguração razoável (conclusão em forma positiva) x limitada (forma negativa).
- Trabalho de certificação (attestation) x trabalho direto.

## Arquivos desta pasta

- `resumo.md` — resumo direcionado (criado quando o tópico for estudado)
- `questoes.md` — questões anteriores comentadas + itens C/E inéditos
- `material/` — conteúdo-base enviado (PDFs, trechos de lei, aulas)
